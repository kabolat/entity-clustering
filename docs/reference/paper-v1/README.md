# Paper-v1 reference artifacts

These five figures are the tracked visual outputs that accompanied the
historical paper implementation. They are retained as fixed references, not as
outputs of the maintained CLI.

The code, notebooks, and ignored CSV result tables that produced them are
preserved by the immutable `paper-v1` tag. Reproduce new runs with the
configuration-driven workflow documented in the repository root instead.

When legacy CSV result tables are present locally, keep them under the ignored
`artifacts/paper-v1/results/` directory rather than at the repository root.
